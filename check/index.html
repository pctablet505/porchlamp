Check an open-source project

Find out what happens to a stranger's pull request at a project, in the Porchlamp snapshot of 17 October 2026.

To check a project, open https://porchlamp.org/projects/<owner>/<name>/ (lower case). For example, WordPress/gutenberg.

    Only the 4,322 ranked projects have a page. A project that is not ranked, and the reason, is listed under Not ranked.
